詳しい登録手順

【STEP 1】初期プログラムの書き込み
工場出荷時の新品基板は、PCからの自動再起動命令を受け取れません。最初の1回目だけは、基板上の白いボタン(BOOTSEL)を押しながらUSBを繋ぎ、すぐ下の「未登録基板へ強制書き込み」を押してください。

【STEP 2】 下の黒い画面に SUCCESS と出て再起動したら、3〜5秒ほど待ってから一度ブラウザをリロード（Cmd+R） します。

【STEP 3】 「USBポート」を選んで「ポートをスキャン」を押すと、ID（例: 4）とホスト名（例: robot-04）を決める画面が出るので登録して完了です！

※一度でもこのプログラムが書き込まれた基板は「賢く」なるため、次回のアップデートからはボタンを押さずにただUSBを挿すだけで書き込めるようになります。

60 mm 復帰性能：B vs 固定校正の曲げ単独

各制御則4試行・各120秒、κ1・Δω0・FB開始10秒。60秒と90秒にID13へ符号を逆にした±30°の位相外乱を加えます。符号順序は試行ごとに交互とし、両制御則で均等にします。

共通校正60秒 → ブロック1（B・曲げ・曲げ・B）→ ブロック2（曲げ・B・B・曲げ）。各ブロック約9分20秒、駆動合計16分。8試行を通して同じ校正値を固定します。

最初に共通校正を選択し、専用FW ota_two_sensor_recovery を両機へ明示的に書き込んでください。校正を回収後、ロボットを再起動せず各ブロックを選択 → 適用 → 読戻し → 自動シーケンス開始。外乱はFW内で自律実行し、制御則も試行間に自動切替します。曲げ単独は従来の移動窓方式ではなく、Bと同じ固定校正で再設計した対照です。

60 mm 曲げ＋電流：B・C各7条件

B：同位相への復帰率を最大化。C：単独の復帰率を保ち残差変動を低減。Δω＝−0.3〜＋0.3 rad/sを0.1刻み・κ1・各120秒、開始10秒からFB、評価60–120秒。B/Cの全条件で直近の60 mm電流Δω=0の開始位相を共通に使います。

①B校正60秒 → ②B7条件・約16分 → ③C校正60秒 → ④C7条件・約16分。各シーケンス後にログを回収します。両センサを同時校正し、閉ループ中は中心・幅を固定します。既存の曲げ単独データは参考比較に使います。

最初に校正条件を選び、専用FWを明示的に書き込んでください。校正後は再起動・パラメータ再取得をせず、本試行を選択 → 校正値・制御則を適用 → 読戻し確認 → 自動シーケンス開始。条件選択だけでは実機に送信しません。各Δωは1回の測定です。ロック範囲・位相差・定常変動を比較します。復帰率や統計的な改善の確証には追加実験が必要です。

60 mm電流FB：Zopt,10・同位相2周期平均

生電流 → MA5 → 現在と前周期の同じ自位相の電流を平均 → 補正済み固定中心・固定幅で正規化 → Zopt,10との積。Z・κ・幅は維持します。

①新規補正測定60秒（周期平均なし・κ0）を回収 → ②2周期平均7点 → ③同じ補正値で追加6点。ID12/13・κ1・各120秒・評価60–120秒・判定36°・保存25 Hz。既存と同じ13点を各1回測定します。

2周期平均対応FWが必要です。条件選択後にパラメータ同期と読戻しを確認し、自動シーケンスで開始してください。履歴は各試行の最初の10秒で蓄積します。補正測定から13点終了までに電池・取り付けを変えた場合は、新しい補正測定からやり直してください。

電流 FB：開始前の中心補正・Zopt,1 vs Zopt,10

各パドル・各Zの13点につき補正測定1回。①κ=0で60秒（ω₁=3π・ω₂=2.9π、保存50 Hz）→ログ回収→10–50秒から機体別の電流増加分を計算→②7点→③追加6点。同じ補正値を13点中固定します。

補正は中心のみ：c′=c+平均［MA5(I)−同定10試行平均の予測電流］。幅・Z・κ・MA5は変更しません。閉ループはκ=1・各120秒・評価60–120秒・保存25 Hz。各条件選択後にパラメータ同期と読戻しを確認し、下の自動シーケンスで開始してください。
